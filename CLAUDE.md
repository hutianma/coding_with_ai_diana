# Pocket Album World

A cozy, creative, social collecting game (web app): players turn their own photos into virtual albums, unbox them for random photocards, keep them in a 3D binder, and later trade with other players.

- **What to build:** [README.md](README.md): game concept, features, tech, data model, roadmap (Phase 1 = M0–M9).
- **How to build it:** [WORKFLOW.md](WORKFLOW.md): the 7-step milestone loop, definition of done, git habits, task breakdowns.

## Key rules
- One milestone per branch (`m<number>-<short-name>`). `main` must always work.
- Show the task breakdown before coding a milestone. Diana approves it first.
- Small commits, one task each. Never push, merge, or deploy without Diana's OK.
- No real people's photos, copyrighted images or music in the repo. Use only placeholder art.
- Must work in iPhone Safari and follow Reduce Motion.
- Diana is learning. Explain changes in plain, friendly language.
- Everything that goes to GitHub (code, comments, commits, docs) is in English, even when Diana writes in Chinese.
